# notes/ — private cahier de laboratoire

This folder is **gitignored**. Anything here is private working notes
that don't belong in the public repo.

## Typical contents

- `decisions.md` — draft pad for ADRs (promote to `docs/decisions/`
  when ready)
- `journal.md` — daily lab journal
- `ideas.md` — brain-dumps
- `kanban_dev.md`, `kanban_experiments.md` — todo lists
- `cahier_laboratoire.md` — scientific protocol notes

## Discipline

- Capture freely here
- Promote to `docs/` when a thought is polished enough to share
- Never commit `notes/` content — it's in `.gitignore` for a reason

## This README

This README is the ONE exception that gets committed (so the folder
exists in the repo). It documents the convention.

# Security policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a vulnerability

Please report security vulnerabilities **privately** by emailing
{{AUTHOR_EMAIL}}.

**Do not** open a public GitHub issue for security vulnerabilities — give us
a chance to fix the issue before it's disclosed publicly.

### What to include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Suggested fix (if you have one)

### Response timeline

- **Acknowledgment** : within 7 days of report
- **Initial assessment** : within 14 days
- **Patch release** : depends on severity, target within 30 days for critical
  vulnerabilities

After the patch is released, we'll publish a security advisory on GitHub
crediting the reporter (unless anonymity is requested).
